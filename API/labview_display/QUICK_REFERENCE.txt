# QUICK REFERENCE - Test Data Display for LabVIEW

## Installation (Run Once)

```bash
cd C:\laragon\www\labview_display
pip install -r requirements.txt
python test_install.py
```

## Calling from LabVIEW - System Exec

### Command Format
```
C:\laragon\www\labview_display\display.bat <fileid> "<stagename>"
```

### Examples

**Example 1 - Static Call**
```
C:\laragon\www\labview_display\display.bat 1 "Stage 1"
```

**Example 2 - Dynamic with Variables**
```
LabVIEW Formula:
"C:\laragon\www\labview_display\display.bat " + Num2Str(file_id) + " \"" + stage_name + "\""
```

**Example 3 - Multiple Concurrent Calls**
```
Call 1 (File 1, Stage 1):
  C:\laragon\www\labview_display\display.bat 1 "Stage 1"

Call 2 (File 1, Stage 2):
  C:\laragon\www\labview_display\display.bat 1 "Stage 2"

Call 3 (File 2, Stage 1):
  C:\laragon\www\labview_display\display.bat 2 "Stage 1"

All 3 windows run independently at the same time!
```

```
                                                      ├──→ [Build String] ──→ [System Exec]
[String Control: StageName] ───────────────────────────┘

                                                   [Display Window]

Build String example:
"C:\laragon\www\labview_display\display.bat " + file_id_string + " \"" + stage_name + "\""
```

## What the Application Does

1. **Receives**: File ID and Stage Name
2. **Queries**: MySQL database for test data
3. **Displays**: Data table with all measurements
4. **Provides**: Interactive graph with Y-axis selector
5. **Shows**: Elapsed time on X-axis, selected measurement on Y-axis

## Key Features

- ✓ Multiple windows can run at the same time
- ✓ Each window is independent
- ✓ Columns automatically match test type
- ✓ Y-axis dropdown to switch measurements
- ✓ Scrollable data table
- ✓ Interactive graph with refresh

## Important Notes

1. **Stage Name is Case-Sensitive**: "Stage 1" ≠ "stage 1"
2. **Always Quote Stage Name**: display.bat 1 "Stage 1" (with quotes)
3. **File ID Must Exist**: Check database if "No Data Found" error
4. **Database Must Be Running**: Start MySQL service before calling
5. **Multiple Calls**: No limit on concurrent displays

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Window doesn't appear | Check System Exec error output, verify file ID and stage name |
| "Connection Failed" | Start MySQL service, run test_install.py |
| "No Data Found" | Verify file ID and stage name match database exactly |
| Y-axis dropdown empty | Check if test type is set in database |
| Data looks incomplete | Verify stage name case matches database |
